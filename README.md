# ANC Audit

## Idea

I thought that a proforma would be great for the audit of the quality of antenatal care at Central Women Hospital, Mandalay, Myanmar. What would be bettter? Taking proforma with our electronic devices - phones, laptops, tablets and ipads.

It will

1. Reduce the cost of printing proforma papers
1. Make restriction of adding wrong data or wrong format data
1. Connect back to the data input person if some data was invalid
1. Reduce the time of adding data into the computer
1. Reduce the wrong input error while adding data into the computer

## About

With the help of Copilot, Gemini, I wrote this website '`ANC Audit`' powered by `Reactjs`, `Nextjs`, `Tailwindcss`, `Shadcn UI`, `Firebase` and `Vercel`.
